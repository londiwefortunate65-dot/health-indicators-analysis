# Health Indicators Analysis — Excel

## Project Overview
This project explores health indicators across Sub-Saharan Africa from 2000 to 2024 using Excel. The analysis aims to identify trends and patterns in health indicators over time and provide insights that can support data-driven decision-making.

## Tools Used
- Microsoft Excel Online
- PivotTables
- Charts and dashboards
- Data analysis and visualization

## Analysis
- Health indicator trends from 2000 to 2024
- Comparisons across Sub-Saharan African countries
- Changes in health indicators over time
- Summary of key patterns using PivotTables and visualizations

## Skills Demonstrated
- Data analysis in Excel
- PivotTable creation and analysis
- Data visualization
- Trend analysis
- Presenting findings clearly

## Dataset
The project uses a health indicators dataset covering the period from 2000 to 2024, with a focus on Sub-Saharan Africa.
